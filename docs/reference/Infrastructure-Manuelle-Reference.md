# Infrastructure manuelle Reference

Inventaire de ce qui est géré à la main dans le dépôt, projet par projet, avec la preuve et la raison de chaque ligne.
Il sert à distinguer le manuel délibéré (une décision écrite le justifie) du manuel par omission (aucune décision
trouvée), et alimente la liste des candidats à une issue.

Instantané du 2026-10-08 (issue 1094), migré le 2026-10-11 ; les lignes n'ont pas été revérifiées. L'instantané a été
pris à `origin/main` (`7b5f3485`). Chaque ligne cite une preuve dans le dépôt ; ce qui n'a pas pu être relié au dépôt
est marqué « non vérifié ».

## Guide de lecture

| Statut                | Signification                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------- |
| **Déclaratif**        | Défini dans du code versionné (Pulumi, ArgoCD/`dist/`, Ansible, Nix, template Omni)       |
| **Manuel (délibéré)** | Une décision écrite donne la raison (ADR, issue, document). Pas un candidat               |
| **Manuel (omission)** | Aucune décision trouvée dans un sens ou dans l'autre. Listé dans la section des candidats |

« Déclaratif » ne dit rien de qui applique la définition. À la date de l'instantané, chaque stack Pulumi, chaque
synchronisation `omnictl` et chaque exécution Ansible est lancée à la main depuis la machine de l'opérateur, et aucun
workflow de `.github/workflows/` n'applique l'infrastructure. C'est délibéré pour Pulumi
([ADR-015](../decisions/ADR-015-Migrer-Crossplane-vers-Pulumi.md), phase 1, statut `accepted` : « aucun job CI, pas même
un `preview` en lecture seule ») et traité ici comme un modèle d'exécution, pas comme un élément manuel.

statut courant. L'ordre n'est pas un tri.

- [x] **10. Corriger la dérive documentaire : TODO des étapes 9/10 de la procédure OMNI, arbre des projets
      d'`AGENTS.md`, README de `talosnet-dns`** : trouvée pendant la construction de cet inventaire. Preuve : constats
      transverses. Statut : fait dans #1291, issue #1287.
- [x] **11. Décider si `kazimierz.akn` doit de nouveau avoir une application automatique** : la suppression
      d'`ansible-pull` laisse un VPS sans réconciliation planifiée et sans raison écrite. Preuve :
      [Initialiser Kazimierz](../guides/Initialiser-Kazimierz.md) ; ADR-008. Statut : décidé non (pas de supervision,
      retour arrière difficile), documenté dans l'ADR-008 ; PR de migration NixOS #1304 ouverte.

## Points non vérifiés

- Si les valeurs des secrets OpenBao sont écrites à la main, par des stacks Pulumi, ou les deux, selon le chemin.
- Si la zone Cloudflare, le tailnet Tailscale et le compte Backblaze ont une IaC quelconque.
- Si l'hôte et la configuration de Home Assistant vivent ailleurs que dans ce dépôt.
- Quel système possède la zone BIND dans laquelle écrit `external-dns-bind`.
- Si les réglages du dépôt GitHub (protection de branche, secrets) sont gérés comme du code ; seuls les labels le sont,
  par `push,schedule.sync-labels.yaml`.
